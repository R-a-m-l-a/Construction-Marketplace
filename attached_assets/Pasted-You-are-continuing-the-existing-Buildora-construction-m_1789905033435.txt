You are continuing the existing Buildora construction marketplace project.

Phase 1 is complete and working. **Do not rebuild or redesign Phase 1. Do not replace Clerk authentication. Do not introduce paid services.**

Now implement **PHASE 2 ONLY: Location + Map Discovery**.

## Main Goal

Build a real, functional location discovery system where a user can:

1. Use their current location
2. Search for a location manually
3. See the selected location on an interactive map
4. Discover nearby construction-related businesses/professionals
5. See discovered results both on the map and in a list
6. Open a result to see useful details

This must use real location/map functionality, not a fake/static map.

---

## 1. Map Technology

Use:

* Leaflet
* React-Leaflet if appropriate for the existing Next.js architecture
* OpenStreetMap map tiles

Do NOT use Google Maps yet.
Do NOT require a Google Maps API key.
Do NOT add billing-dependent services.

Make sure the map works correctly with Next.js client-side rendering.

Handle Leaflet's SSR/browser issues properly.

## 2. Location UI

Add a clear location discovery section to the appropriate existing Buildora page.

The user should see:

**"Find construction services near you"**

with two primary options:

### Option A — Current Location

Button:

**📍 Use my current location**

When clicked:

* Request browser geolocation permission
* Get latitude and longitude
* Center the map on the user's location
* Show a marker for the user's location
* Search for nearby construction-related places

If permission is denied, show a friendly message explaining that the user can search manually instead.

Do not repeatedly request permission.

### Option B — Search Location

Provide a search input:

**"Search city, area or location..."**

Examples:

* Islamabad
* Peshawar
* Hayatabad
* Lahore
* University Road, Peshawar

When the user searches:

* Geocode the location using a free OpenStreetMap-compatible geocoding service such as Nominatim
* Get latitude and longitude
* Center the map on the searched location
* Show a location marker
* Search for nearby construction-related places

Do not hard-code Islamabad or any other city.

## 4. Nearby Construction Discovery

For the free-first MVP, use OpenStreetMap data where practical.

Search for relevant construction-related categories such as:

* Construction companies
* Contractors
* Architects
* Civil engineers
* Interior designers
* Building material suppliers
* Hardware stores
* Electrical shops
* Plumbing services
* Paint stores
* Sanitary stores
* Tile stores
* Real-estate/construction-related businesses where appropriate

Use an appropriate OpenStreetMap-compatible source/query mechanism such as Overpass where suitable.

IMPORTANT:

Do not pretend that OpenStreetMap contains every business.

If no nearby results are found, clearly tell the user:

"No construction services were found nearby. Try searching another area."

Do not generate fake businesses.

## 7. Distance

If the user's location or selected coordinates are available:

Calculate approximate distance between the selected location and each result.

Display something like:

"1.4 km away"

Use a simple geographic distance calculation such as the Haversine formula.

Do not call an external routing API just to calculate distance.
