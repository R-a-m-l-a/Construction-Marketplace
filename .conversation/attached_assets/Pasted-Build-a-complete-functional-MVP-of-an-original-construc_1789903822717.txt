Build a complete, functional MVP of an original construction marketplace and professional-discovery web application for Pakistan.

The product should be inspired by the general concept of construction marketplaces such as Tameer.ai, but MUST have its own brand identity, UI, text, layout, components and design. Do not copy Tameer.ai's branding, images, content, or exact UI.

The goal is a REAL working prototype that I can deploy and give to 5–6 real users for testing.

Do NOT build a static mockup. Core features must actually work.

Use:

* Next.js

# AI COST CONTROL

This application is being built on a limited/free development plan.

Optimize API usage.

Rules:

* Do not call OpenAI for simple UI operations.
* Do not call Google Places automatically when pages load.
* Only call Google Places after a user search/location request.
* Do not continuously poll APIs.
* Do not make duplicate API calls.
* Cache appropriate results where permitted.
* Do not create unnecessary AI agents.
* Use a single AI assistant with a small number of tools.

The goal is a useful MVP, not a massive autonomous agent.
